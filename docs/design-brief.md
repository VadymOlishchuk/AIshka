# ТЗ на редизайн AIshka

Документ для Pencil. Копіюй цілком або секціями.

Мова інтерфейсу — **англійська**. Весь текст у макетах англійською, дослівно як
наведено. Коментарі ТЗ — українською, у макети не потрапляють.

## 0. Слот візуального напряму

**⚠️ Заповни перед подачею в Pencil.**

```
ВІЗУАЛЬНИЙ НАПРЯМ: [ встав сюди посилання або опис референсу ]
Настрій:           [ напр. спокійний / грайливий / преміальний / технічний ]
Що саме сподобалось: [ типографіка / кольори / щільність / ілюстрації / рух ]
```

Решта документа задає **структуру, контент і стани** — вони не залежать від
візуального напряму й не змінюються. Pencil має свободу в кольорі, типографіці,
формі й ілюстраціях, але не у складі екранів і не в текстах.

## 1. Що це за продукт

AIshka — платформа навчання роботі з AI для людей без технічного бекграунду.

Головна механіка: людина проходить онбординг → отримує **персональний план**
з уроків, зібраний з її відповідей → проходить уроки з квізами → бачить прогрес.
Окремо є **Академія** — повний каталог, доступний поза планом.

Масштаб на сьогодні: **172 уроки, 23 курси, 6 полиць**.

Аудиторія: 25–45 років, не програмісти. Бухгалтери, вчителі, HR, дизайнери,
продавці, рієлтори. Читають з телефона так само часто, як з ноутбука.

Тон: спокійний, конкретний, без хайпу. Продукт не обіцяє «змінити життя за
7 днів» — він обіцяє одну навичку за урок.

## 3. Дизайн-система

### 3.1 Що зберегти з поточної

Ці рішення виміряні на живому продукті й працюють. Змінювати можна значення,
але **не структуру**:

```
--container-reading: 668px   /* колонка тексту уроку — не ширше, читається погано */
--container-action:  408px   /* приклеєна кнопка внизу уроку */
--radius-l: 16px             /* кнопки, великі картки, панелі */
--radius-m: 10px             /* картки курсів, варіанти квізу */
--radius-s: 8px
```

Поточна палітра (референс, не догма):

```
accent        #a172ff   головна дія, прогрес, активний стан
accent-tint   #f8f5ff   підкладка вибраного варіанта
ink-strong    #161a1b   заголовки
ink-body      #464a4d   текст уроку
ink-muted     #7b8188   метадані, підписи
canvas        #f6f7f9   фон сторінки
surface       #ffffff   картки, панелі, шапка
line          #dfe1e5   межі, порожній трек прогресу
success       #4caf7d   правильна відповідь
error         #e08a7d   помилка (навмисно м'який, не червоний)
pair-b        #e8a33c   друга складена пара в AI Task
```

**Про `error`:** він свідомо приглушений. Помилка в квізі — не катастрофа,
а нормальна частина навчання. Яскраво-червоний тут карає. Збережи цю логіку
в новому напрямі, навіть якщо колір зміниш.

### 3.2 Типографіка — задати заново

Потрібна шкала на 7 рівнів. Обов'язкові вимоги:

- Текст уроку — **18px, висота рядка 1.6, вирівнювання по лівому краю**.
  Не justify: у вузькій колонці з'являються «річки».
- Заголовок у тексті уроку — 24px, `text-wrap: balance`.
- Мінімальний розмір будь-якого тексту — 13px.

### 3.3 Сітка й відступи

- Шкала відступів кратна 4.
- Контент-максимум: 1120px, колонка уроку: 668px.
- Брейкпоінти: 390 (телефон), 768 (планшет), 1440 (десктоп).

### 3.4 Рух

Стримано. Три дозволені анімації:

- поява картки — 150 мс, зсув на 4px
- зміна стану кнопки — 100 мс
- святкування завершення (§21) — єдине місце, де рух помітний

Все інше — миттєво.

## 4. Компоненти

Кожен намалювати **в усіх станах**. Стани — не деталь, це половина роботи.

### 4.1 Кнопка

Варіанти: `primary`, `secondary`, `ghost`, `destructive`.
Стани: `default`, `hover`, `active`, `focus-visible`, `disabled`, `loading`.
Розміри: `s` (32), `m` (40), `l` (48).

`focus-visible` обов'язковий — це доступність з клавіатури, не прикраса.

### 4.2 Картка курсу

Вміст: іконка (емодзі, 24px), назва, опис на 2 рядки, кількість уроків, смуга
прогресу.

Стани: `not started`, `in progress` (з відсотком), `completed` (галочка),
`locked` (замок + причина).

### 4.3 Плитка іконки

Квадрат зі скругленням, емодзі всередині. **Фолбек обов'язковий:** якщо іконки
немає — згенерована обкладинка з градієнтом, виведеним з назви курсу.
Порожній сірий квадрат — дефект, ми його вже виправляли.

### 4.4 Смуга прогресу

Два варіанти: тонка (4px, у картці) і товста (8px, у шапці плану).
Показує відсоток. Порожній трек — колір `line`.

### 4.5 Акордеон юніта

Заголовок: іконка, назва юніта, «3 of 5 lessons», шеврон.
Розгорнутий: список уроків. Кожен урок — назва, тривалість, статус
(`done` / `current` / `todo`).

### 4.6 Квіз

Питання, 4 варіанти, кнопка Check.

Стани варіанта: `default`, `selected`, `correct`, `wrong`, `disabled-after-answer`.

**Критично:** після неправильної відповіді правильна **не підсвічується**.
Показується лише банер-підказка, що дає напрямок думки. Ми цей баг вже
виправляли — не повертай його.

Довжина варіантів вирівняна — інакше правильну відповідь видно на око.

### 4.7 Банер результату

`success`: заголовок з емодзі + пояснення, чому саме так.
`wrong`: підказка напряму. Не відповідь.

### 4.8 Блок AI Task

Модалка. Механіка: скласти 3 пари (ліва картка ↔ права картка).
Стани пари: `unmatched`, `matched-a` (accent), `matched-b` (pair-b), `wrong`.
Внизу — підказка при невдачі. Завдання **необов'язкове**, має бути помітний
спосіб пропустити.

### 4.9 Оцінка уроку

Компактний рядок після завершення: «Was this useful?» + 👍 / 👎.
Після натискання — розкривається поле коментаря.

**Критично:** поле коментаря не має зникати при першому натисканні клавіші.
Це теж вже виправлений баг.

### 4.10 Блоки уроку — 10 типів

Кожен намалювати:

| Тип | Що це |
|---|---|
| `text` | Заголовок + HTML-абзац. До 110 слів. |
| `quote` | Виділена думка на всю ширину колонки |
| `try` | Список кроків «спробуй сам», 4 пункти |
| `quiz` | §4.6 |
| `ai_task` | §4.8 |
| `match_pairs` | Вбудований варіант пар |
| `summary` | Підсумок + тізер наступного уроку |
| `image` | Ілюстрація з підписом |
| `video` | **Ще жодного разу не використаний — намалювати з нуля** |
| `youtube` | Вбудований плеєр |

### 4.11 Шапка

Логотип, навігація, пошук, лічильник серії, аватар.
На мобільному згортається — див. §19.

## 6. Автентифікація

Чотири екрани, одна форма-компонент.

- **Register:** email, пароль, кнопка. Вимоги до пароля показані одразу,
  не після помилки.
- **Login:** email, пароль, «Forgot password?».
- **Reset:** email → екран «Check your inbox».
- **Set password:** новий пароль + підтвердження.

Стани для кожного: `default`, `loading`, `field error`, `form error`.

Текст помилки — конкретний. Не «Something went wrong», а «This email is
already registered».

виглядає як помилка. Потрібне рішення — або інша розкладка, або картка
«More coming».

## 9. AI-чат — НОВЕ

Найважливіший з ненамальованих екранів. Маршрут `/dashboard/ai`.

**Розкладка:** ліва панель зі списком розмов, права — чат.
На мобільному панель — висувна шухляда.

**Компоненти:**

- список розмов: назва, дата, кнопка видалення при наведенні
- повідомлення: користувач (вирівняне праворуч) / асистент (ліворуч)
- поле вводу: автовисота, `Enter` — надіслати, `Shift+Enter` — новий рядок
- кнопка «Stop» під час генерації
- **лічильник квоти** — «12 of 30 messages today». Критичний елемент:
  без нього людина впирається в ліміт несподівано і це виглядає як поломка
- вибір моделі (селектор, 2–3 опції)
- стан «квота вичерпана» — з поясненням, коли оновиться, і кнопкою тарифу

**Стани:** порожній чат (з підказками-стартерами), генерація (курсор або
крапки), помилка мережі з кнопкою «Retry», квота вичерпана.

**Стартери в порожньому стані** — 4 картки з готовими запитами, взяті
з бібліотеки промптів.

## 11. Пейволл і тарифи — НОВЕ

Два місця:

**Сторінка `/pricing`.** 2–3 тарифи картками. Порівняння за рядками.
Річна знижка перемикачем. Без темних патернів: без фальшивих таймерів,
без «залишилось 2 місця».

**Вбудований замок.** Коли урок недоступний — картка на місці контенту:
що саме закрито, що дає підписка, кнопка. Не модалка на весь екран поверх
уроку — це дратує.

Також: стан «підписка активна» в профілі, стан «підписка скасована,
діє до 14 квітня».

## 12. Воронка, 28 кроків — НОВЕ

Маркетинговий квіз до реєстрації. Маршрут `/quiz/[step]`.

Один екран — одне питання, як в онбордингу, але **візуально інший**:
це ще не продукт, це продажі. Дозволено більше емоції.

Типи кроків:
- питання з варіантами
- питання з повзунком
- екран-твердження («83% of people who answered like you…») — соціальний доказ
- екран завантаження з прогресом («Building your plan…»)
- фінальний екран з результатом і платежем

Індикатор прогресу обов'язковий. 28 кроків без нього — це вихід зі сторінки.

## 14. Сертифікат — НОВЕ

Після завершення курсу. Дві частини:

**Екран отримання:** привітання, прев'ю сертифіката, кнопки «Download» і
«Share on LinkedIn».

**Сам сертифікат:** макет для експорту в PNG. Ім'я, назва курсу, дата,
кількість уроків, підпис платформи. Розмір під LinkedIn (1200×630).

## 15. Серії й досягнення — НОВЕ

- **Лічильник серії** в шапці: полум'я + число днів.
- **Календар серії:** 7 днів тижня, відмічені виконані.
- **Значки:** сітка досягнень. Стани `earned` / `locked` (силует + умова).
  Мінімум 12 значків.
- **Сповіщення про серію під загрозою** — м'яке, без тиску й провини.

- **Сторінка `/dashboard/saved`:** дві вкладки — Bookmarks / Notes.
  Нотатка в списку показує урок, фрагмент і дату.

## 17. Сповіщення та листи — НОВЕ

**У застосунку:** тост зверху праворуч. Варіанти `success`, `error`, `info`.
Автозникнення 4 с, кнопка закриття.

**Листи** — намалювати 5 шаблонів:
1. підтвердження реєстрації
2. скидання пароля
3. нагадування про серію
4. новий курс на полиці
5. чек про оплату

Листи — вузька колонка 600px, мінімум зображень, велика кнопка дії.

## 18. Порожні, помилкові й завантажувальні стани — НОВЕ

Ці стани зараз не намальовані ніде. Потрібні:

| Стан | Де |
|---|---|
| План порожній | до онбордингу |
| Полиця порожня | Академія |
| Нічого не знайдено | пошук |
| Немає закладок | `/dashboard/saved` |
| 404 | будь-де |
| 500 | будь-де |
| Немає мережі | глобальний банер |
| Скелетон картки | Академія при завантаженні |

## 19. Мобільна навігація — НОВЕ

Нижня панель, 4 пункти: **Home / Learn / AI / Profile**.
Активний стан помітний. Висота 56px + безпечна зона.

Плеєр уроку на мобільному: панель ховається, кнопка «Continue» приклеєна
внизу на всю ширину.

## 20. Розширені налаштування — НОВЕ

Секції в `/dashboard/profile`:

- **Account:** ім'я, email, зміна пароля
- **Subscription:** тариф, дата списання, скасування
- **Email preferences:** перемикачі на кожен тип листа
- **Sessions:** список активних сесій, «Sign out everywhere»
- **Danger zone:** видалення акаунта з підтвердженням

## 21. Святкування завершення — НОВЕ

**Урок завершено:** компактно, у потоці. Галочка, «Lesson complete»,
кнопка наступного уроку. Без модалки — вона перериває ритм.

**Юніт завершено:** помітніше. Картка з підсумком.

**Курс завершено:** повноекранно. Конфеті (єдине місце, де дозволена
помітна анімація), підсумок, сертифікат, що далі.

## 22. Тіньова тема — НОВЕ

Повна палітра для темного режиму. Не інверсія — окремий підбір.

Особливо перевірити: `accent` на темному тлі, `success`/`error` банери,
читабельність тексту уроку 18px, скругління й межі карток.

Перемикач: Light / Dark / System.

## 23. Що віддати

**Формат:** `.pen`, окремі сторінки за секціями цього ТЗ.

**Ширини:** 1440 і 390 для кожного екрана. 768 — тільки для Академії,
плеєра уроку й чату.

**Обов'язково:**
- бібліотека компонентів (§4) з усіма станами як варіантами
- токени як змінні, не як захардкоджені значення
- назви шарів людські: `card/course/in-progress`, не `Frame 247`

**Пріоритет, якщо на все не вистачить:**

1. Дизайн-система і компоненти (§3, §4)
2. Плеєр уроку (§4.10) — тут людина проводить 90% часу
3. Академія і план (§8)
4. AI-чат (§9)
5. Стани (§18)
6. Решта

## 24. Чого не робити

- Не змінюй склад екранів і тексти — це не косметика, це контракт з кодом.
- Не підсвічуй правильну відповідь після помилки (§4.6).
- Не роби порожніх сірих квадратів замість іконок (§4.3).
- Не став модалку поверх уроку для пейволла (§11).
- Не використовуй темні патерни в тарифах (§11).
- Не додавай анімації поза трьома дозволеними (§3.4).
- Не роби текст уроку вужчим за 600px і ширшим за 668px.
