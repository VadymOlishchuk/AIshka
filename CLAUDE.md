# AIshka

Навчальна платформа: персональний план уроків, який збирається з відповідей
онбордингу, плеєр уроку з квізами й прогрес. Повна документація — «План збірки
LMS», частина 4 (артефакт). Тут — лише те, що потрібно щодня.

## Пріоритети

Платформа й наповнення першими. Маркетингова воронка на 28 кроків, Stripe і
AI-чат — наступні етапи; схема БД і гейт доступу вже готові до них.

## Команди

```
docker compose up -d        # Postgres на localhost:5433
pnpm dev                    # застосунок
pnpm db:migrate             # міграція після зміни schema.prisma
pnpm content:check          # гейт публікації без запису в БД
pnpm content:sync           # валідація + імпорт контенту в БД
pnpm typecheck              # tsc --noEmit
```

## Рішення, які не переобговорюємо

- **Один застосунок Next.js**, домен — у `src/core` (без React і Next-залежностей).
  Це шов: коли з'явиться другий клієнт, `src/core` виноситься в окремий сервіс.
- **Контент живе в git** (`content/*.json`), а не редагується руками в БД.
  `content:sync` валідує й заливає. Це дає код-рев'ю на контент і відкат одним `git revert`.
- **Гейт публікації** (`src/core/content/course.ts`) — обов'язковий. Урок, який його
  не пройшов, у базу не потрапляє. Без нього каталог швидко наповнюється дефектами.
- **Прогрес прив'язаний до трійки** `(userId, lessonId, courseId)`. Той самий урок
  у різних курсах — різні досягнення.
- **Доступ перевіряється двічі**: `src/proxy.ts` вирішує маршрут, `requireActiveAccess()`
  захищає ресурс. Приховати кнопку в UI — не захист.
- **Формат відповіді API** — `{ok:true,data}` / `{ok:false,error:{code,message,fields?}}`.
  Клієнт ніколи не парсить текст повідомлення, тільки `code`.
- **Токени**: короткий JWT у cookie `at` (15 хв) + непрозорий refresh у `rt` (30 днів,
  ротація з виявленням повторного використання). Обидві cookie — HttpOnly.

## Правила контенту

Урок: 8–14 блоків, 400–1400 слів, текстовий блок ≤110 слів, обов'язкові квіз і summary
з тізером. Варіанти квізу вирівняні за довжиною — інакше правильну відповідь видно на око.
Банер помилки дає напрямок думки, а не відповідь. Повні правила — у розділах 21–22 плану збірки.
